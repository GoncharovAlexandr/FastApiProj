# Практическая работа №2. Развитие AI-сервиса агроскоринга

## 1. Цель работы

Цель работы — расширить REST API агроскоринга, созданный в практической работе №1, механизмами сквозной идентификации запросов, middleware, асинхронного хранения результатов в SQLite, пакетного и динамического инференса, backpressure, timeout и интеграции внешней LLM.

## 2. Краткое описание расширенной архитектуры

Клиент отправляет HTTP/JSON-запрос в FastAPI. Middleware принимает `X-Request-ID` или создаёт UUID, сохраняет его в `request.state`, добавляет в ответ заголовки `X-Request-ID` и `X-Process-Time`, а также записывает информацию о запросе в лог. Входные данные проверяются Pydantic-моделями, после чего сервис проверяет допустимость региона и рассчитывает оценку риска.

Результаты хранятся в SQLite через асинхронный драйвер `aiosqlite`. Для пакетных запросов применяется `executemany` и один `commit`. Endpoint `/predict-queued` помещает одиночный запрос в ограниченную `asyncio.Queue`; worker объединяет запросы в пакет размером до 8 элементов или по истечении 50 мс. При заполнении очереди сервис возвращает `429`, а при превышении таймаута инференса — `504`.

Внешняя LLM вызывается через `httpx.AsyncClient`. Endpoint `/llm/chat` возвращает текстовый ответ модели. Endpoint `/predict-with-llm` сначала рассчитывает `risk_score` и `risk_level` правилами агроскоринга, затем просит LLM объяснить результат. LLM не изменяет числовую оценку или категорию риска.

## 14. Вывод

В ходе практической работы API агроскоринга был расширен средствами наблюдаемости, асинхронного хранения и обработки запросов. `request_id` связывает HTTP-запрос, лог и записи в SQLite. Explicit batching обрабатывает переданный клиентом список объектов одним вызовом модели и записывает результаты одной транзакцией. Dynamic batching накапливает одиночные запросы в ограниченной очереди, а backpressure предотвращает неконтролируемый рост очереди. Таймаут защищает сервис от слишком долгого инференса. Интеграция LLM позволяет формировать естественно-языковое объяснение, не передавая ей право изменять риск-оценку.
